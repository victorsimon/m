## Intent
Develop and refine, through iterations, a task- and problem-resolution methodology applicable at any scale, and its implementation in the Pi agent ecosystem. Ordinary iterations start from an impeccable state. A repair iteration may start from an uncertified state; every iteration must deliver an impeccable state before it closes. Determinism and quantification are the core of the methodology. No slop is admitted, not even once: an accepted slop becomes precedent, and precedent becomes norm.

## Criteria
- Ordinary work may start or resume only from a state that passes every verification defined so far.
- When a verification fails, a repair iteration may start solely to repair or replace that verification. Its starting state must not be declared impeccable.
- An iteration closes only when its result passes every verification defined so far.
- Everything can be quantified and classified; concepts such as tolerability are derived from that quantification and classification.
- The same verification applied twice to the same artefact gives the same result.
- There are no invariants: anything may evolve, change, disappear, be created or move.
